网站说明

本站是做什么的

这是面向基础偏弱本科生的深度学习辅导站：按章节自学、用勾选过关、跟 Cursor 做复现与创新验证，最后按顶会结构写英文论文。不是资料堆，也不是只讲概念的 PPT。

  1. 01

    八章循序教程

    从 Python 安装与语法，到 NumPy、机器学习直觉、PyTorch 训练循环，再到 Fashion-MNIST 小项目。每章有细讲、示例和「过关自检」勾选，浏览器会记住你的勾选进度。

  2. 02

    AI 复现开源仓库

    教你怎么把 GitHub 项目拉到本地，用 Cursor / Codex 读 README、装依赖、跑通最小 demo。重点是「一次一事 + 自己验收」，不是让 AI 代写整份作业。

  3. 03

    创新点验证流程

    按固定标准走：单点 A、B 分别调参超过 baseline，再做 Full 同时超过两个单点，然后做参数分析、可视化与错误分析。辅导成功标准写死在第七章，不要让 AI 自行改过关条件。

  4. 04

    顶会论文写作模板

    按摘要 → 四段论引言 → 相关工作 → 方法 → 实验 → 结论讲解；附英文 main.tex 与真实文献 refs.bib，并给出可复制的 Cursor 按节提示词。

  5. 05

    怎么用这个网页

    从上到下点「先学什么」进章节；每章目录可跳转；做完勾选过关项。需要节奏参考时看「学习节奏」。建议：地基五章过完再进 AI 复现与创新点，最后写作。

解决的核心问题：很多人还没立住 Python、数据和训练循环，就直接跳进模型与论文。本站按「能独立跑通一个小实验」排内容，数学只讲够用的部分。

第二部分

如何用 AI 工具写代码

AI 是加速器，不是替你交作业的人。无论用 Cursor、Codex 还是 ChatGPT，都要学会提问、拆任务、验收结果。下面是原则摘要；完整实操（含「复制 GitHub 链接 → 拉到本地 → 让 AI 帮你跑起来」）见专章。

进入：用 AI 复现代码

0. 常用工具（选其一深入即可）

Cursor：AI 编程编辑器，适合打开整个仓库追问与改错。Codex：OpenAI 的 AI 编程助手，流程同类。ChatGPT：适合讲清报错思路。工具不同，验收标准一样。

1. 复现开源：先 clone，再问 AI

复制 GitHub 地址 → git clone 到本地 → 用 Cursor 打开该文件夹 → 让 AI 先读 README 给「最小可运行步骤」，再装依赖、再执行。细节与提示词见 第六章。

2. 一次只要一小块

导读 / 安装 / 下数据 / 运行分开做。不要一句「全部帮我跑好」。

3. 必做三件验收

能运行；输出或文件是否符合 README；结果是否合理（别只看「没报错」）。

4. 报错要原样贴

完整 Traceback + 你已执行的命令 + Windows / venv 信息。

5. 红线自己盯

不跑来路不明脚本；不泄露密钥；数据路径与指标以你验收为准。

提问模板（可直接复制）

我是本科生，在做 [任务]。
环境：Python [版本]，PyTorch，数据在 [路径]。
请只写 [读数据 / 模型 / 训练循环] 这一段。
约束：不要改我的指标定义；变量名尽量短；每步加一句中文注释说明在做什么。
若缺信息，先问我，再写代码。

怎么安排

建议学习节奏

按每周 6–8 小时估算。赶作业可以压缩，但不要跳过 Python 与 NumPy。

  • 第 1–2 周Python + 虚拟环境，每天写一点能跑的脚本
  • 第 3 周NumPy 与画图，做一组假数据实验
  • 第 4 周机器学习直觉 + 第一个训练循环
  • 第 5–6 周小项目 + GitHub 复现
  • 其后创新点文档 → 单点超 baseline → Full 超单点 → 分析出图
